النظام الآن تطبيق ويب متصل بخادم API وقاعدة بيانات دائمة، وليس صفحة HTML مستقلة.

تعليمات تثبيت وتشغيل الخادم المحلي ونشر PostgreSQL موجودة في:
server/README.md

للتشغيل المحلي، افتح http://127.0.0.1:8000 بعد تشغيل الخادم وإنشاء أول مدير
من أمر bootstrap. لا تفتح smart_system_local.html مباشرة من مستكشف الملفات؛
الواجهة تحتاج إلى API والجلسة الخادمية.

الإنتاج يستخدم PostgreSQL خلف TLS بواسطة Docker Compose وCaddy. لا يوجد حساب
مدير أو كلمة مرور افتراضية؛ ينشئ المشغّل الحساب الأول تفاعليًا. لا تُرفع ملفات
.env أو كلمات المرور إلى المستودع.

smart_system.html نسخة واجهة قديمة محفوظة كمرجع، وليست مسار تشغيل الإنتاج.
صدّر بيانات IndexedDB القديمة إلى JSON قبل الانتقال، ثم استعدها بعد تسجيل
الدخول كمدير في النسخة الجديدة. لا تُستورد الحسابات القديمة أو كلمات مرورها.
